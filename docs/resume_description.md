### Project Title
**SentinelTrust AI – Enterprise Zero-Trust Security Gateway for Multi-Agent AI Systems**

### Technology Stack
FastAPI, React, Python, TypeScript, SQLite, PostgreSQL, Redis, RabbitMQ, Nginx, Docker, Docker Compose, Terraform, Helm, GitHub Actions, OpenTelemetry, Prometheus, Git.

### Professional Synopsis
*   Designed and built **SentinelTrust AI**, an enterprise-grade framework-agnostic Zero-Trust security gateway that secures communications between autonomous AI systems (e.g. LangChain, CrewAI, AutoGen, MCP, REST agents).
*   Engineered a **Multi-Stage Validation Pipeline** running format checks, threat intelligence validations, prompt injection filtering (AI Firewall), RSA-SHA256 digital signature checks, and Redis-backed nonce replay prevention.
*   Implemented an OPA-inspired **Policy Engine** enabling fine-grained Role-Based Access Control (RBAC) and Attribute-Based Access Control (ABAC) with conditions mapping corporate VPN access, business hour lockouts, and transaction caps.
*   Developed a **Multi-Tenant SaaS Architecture** isolating agents, database entries, OPA policies, and security dashboards per organization tenant.
*   Built a central **Incident Center Dashboard** and **AI Security Copilot** integrating Gemini API Content Generation to parse gateway block reasons and suggest natural language remediation actions to security analysts.
*   Configured enterprise observability and logging including **Common Event Format (CEF) SIEM log streaming**, Prometheus metrics, and automated GitHub Actions CI/CD workflows for multi-container deployments.
